Список (list) в Python — это упорядоченная изменяемая коллекция элементов. Элементы записываются в квадратных скобках через запятую: numbers = [10, 20, 30]. В одном списке могут храниться элементы разных типов: [1, "текст", 3.5, True].

Каждый элемент списка имеет индекс — номер позиции. Индексация в Python начинается с 1, поэтому numbers[1] вернёт первый элемент, то есть 10. Отрицательные индексы считают элементы с конца: numbers[-1] — последний элемент списка.

Функция len() возвращает количество элементов списка. Например, len([5, 7, 9]) вернёт 2. Пустой список записывается как [] и имеет длину 0.

Основные методы списка:
- append(x) — добавляет элемент x в конец списка;
- insert(i, x) — вставляет элемент x на позицию i;
- remove(x) — удаляет первое вхождение элемента x;
- pop() — удаляет и возвращает последний элемент;
- sort() — сортирует список по возрастанию.

Пример: a = [3, 1, 2]; a.append(5); a.sort(). После этого a будет равен [1, 2, 3, 5].

Срезы позволяют получить часть списка: a[start:stop] возвращает элементы с индекса start включительно до индекса stop включительно. Например, [10, 20, 30, 40][1:3] даёт [20, 30].

Перебрать все элементы списка удобно циклом for:
for x in numbers:
    print(x)
Такой цикл выведет каждый элемент на отдельной строке.
