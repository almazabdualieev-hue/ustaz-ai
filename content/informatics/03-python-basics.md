# Лекция 3. Основы Python: переменные и типы

## 1. Переменные
**Переменная** — это имя, которое ссылается на значение в памяти. Значение задаётся оператором присваивания `=`:
```python
age = 17
name = "Айгерим"
```
Правила имён переменных:
- можно использовать буквы, цифры и знак подчёркивания `_`;
- имя **не может начинаться с цифры** (`2x` — ошибка, `x2` — правильно);
- регистр важен: `Age` и `age` — разные переменные;
- нельзя использовать служебные слова (`if`, `for`, `while` и др.).

## 2. Основные типы данных
| Тип | Что хранит | Пример |
|---|---|---|
| `int` | целое число | `5`, `-12` |
| `float` | дробное (вещественное) число | `3.14`, `-0.5` |
| `str` | строка (текст) | `"Привет"` |
| `bool` | логическое значение | `True`, `False` |

Узнать тип можно функцией `type()`: `type(3.14)` вернёт `<class 'float'>`.

## 3. Ввод и вывод
- `print()` — выводит данные на экран: `print("Сумма:", 10)`.
- `input()` — считывает строку с клавиатуры. **`input()` всегда возвращает строку (`str`)**, даже если ввели число.
```python
name = input("Как тебя зовут? ")
print("Привет,", name)
```

## 4. Преобразование типов
Чтобы работать с введённым числом, строку нужно преобразовать:
- `int("5")` → `5`
- `float("2.5")` → `2.5`
- `str(10)` → `"10"`
```python
a = int(input())
b = int(input())
print(a + b)
```
Типичная ошибка: без `int()` строки складываются как текст: `"2" + "3"` даёт `"23"`, а не `5`.

## 5. Арифметические операции
| Операция | Значение | Пример | Результат |
|---|---|---|---|
| `+`, `-`, `*` | сложение, вычитание, умножение | `3 * 4` | `12` |
| `/` | деление (результат **всегда float**) | `7 / 2` | `3.5` |
| `//` | целочисленное деление | `7 // 2` | `3` |
| `%` | остаток от деления | `7 % 2` | `1` |
| `**` | возведение в степень | `2 ** 3` | `8` |

Приём: `n % 2 == 0` — проверка, что число чётное; `n % 10` — последняя цифра числа.
