# Лекция 4. Условия и циклы в Python

## 1. Условный оператор if
Оператор `if` выполняет блок команд, только если условие истинно. Блок выделяется **отступом в 4 пробела**, после условия ставится двоеточие.
```python
x = int(input())
if x > 0:
    print("положительное")
elif x == 0:
    print("ноль")
else:
    print("отрицательное")
```
- `elif` (сокращение от else if) — дополнительная проверка;
- `else` — выполняется, если ни одно условие не подошло.

## 2. Операции сравнения и логические операции
Сравнение: `==` (равно), `!=` (не равно), `<`, `>`, `<=`, `>=`.
Важно: `=` — присваивание, `==` — сравнение.
Логические операции:
- `and` — истинно, если истинны **оба** условия: `x > 0 and x < 10`;
- `or` — истинно, если истинно **хотя бы одно**: `x < 0 or x > 100`;
- `not` — отрицание: `not x > 5`.

## 3. Цикл for и функция range
Цикл `for` повторяет действия для каждого элемента последовательности.
- `range(5)` → 0, 1, 2, 3, 4 (**правая граница не включается**);
- `range(1, 6)` → 1, 2, 3, 4, 5;
- `range(0, 10, 2)` → 0, 2, 4, 6, 8 (третий аргумент — шаг).

Пример: сумма чисел от 1 до $n$.
```python
n = int(input())
s = 0
for i in range(1, n + 1):
    s = s + i
print(s)
```

## 4. Цикл while
Цикл `while` повторяет действия, **пока условие истинно**. Используется, когда число повторений заранее неизвестно.
Пример: количество цифр в числе.
```python
n = int(input())
count = 0
while n > 0:
    n = n // 10
    count = count + 1
print(count)
```
Опасность: если условие никогда не станет ложным, цикл будет **бесконечным**. Внутри цикла должна меняться переменная из условия.

## 5. Операторы break и continue
- `break` — досрочно **завершает** цикл;
- `continue` — пропускает оставшуюся часть текущего шага и **переходит к следующему**.
```python
for i in range(1, 10):
    if i % 3 == 0:
        continue   # пропускаем числа, кратные 3
    if i > 7:
        break      # останавливаемся после 7
    print(i)       # выведет 1 2 4 5 7
```
