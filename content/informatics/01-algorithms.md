# Лекция 1. Алгоритмы и блок-схемы

## 1. Что такое алгоритм
**Алгоритм** — это конечная последовательность точных инструкций (команд), выполнение которых приводит к решению поставленной задачи.
**Исполнитель** — тот, кто выполняет алгоритм: человек, компьютер, робот.
Пример из жизни: алгоритм заваривания чая — вскипятить воду, положить заварку в чайник, залить кипятком, подождать 5 минут, разлить по чашкам.

## 2. Свойства алгоритма
- **Дискретность** — алгоритм разбит на отдельные шаги, которые выполняются по очереди.
- **Понятность** — каждая команда понятна исполнителю и входит в его систему команд.
- **Определённость (детерминированность)** — каждая команда однозначна; при одних и тех же исходных данных получается один и тот же результат.
- **Результативность** — алгоритм приводит к результату (или к сообщению, что решения нет).
- **Конечность** — алгоритм завершается за конечное число шагов.
- **Массовость** — алгоритм подходит для целого класса задач с разными исходными данными.

## 3. Способы записи алгоритмов
1. **Словесный** — на естественном языке (как рецепт).
2. **Графический** — в виде блок-схемы.
3. **Псевдокод** — полуформальный язык, похожий на язык программирования.
4. **Программа** — запись на языке программирования (например, Python).

## 4. Элементы блок-схемы
| Фигура | Назначение |
|---|---|
| Овал (скруглённый прямоугольник) | Начало и конец алгоритма |
| Параллелограмм | Ввод и вывод данных |
| Прямоугольник | Действие (вычисление, присваивание) |
| Ромб | Условие (проверка), имеет два выхода: «да» и «нет» |
| Стрелки (линии потока) | Порядок выполнения шагов |

## 5. Базовые алгоритмические структуры
Любой алгоритм можно построить из трёх структур:
- **Следование (линейный алгоритм)** — команды выполняются одна за другой.
  Пример: ввести $a$ и $b$, вычислить $s = a + b$, вывести $s$.
- **Ветвление** — выбор действия в зависимости от условия.
  Пример: найти большее из двух чисел — если $a > b$, вывести $a$, иначе вывести $b$.
- **Цикл** — повторение действий, пока выполняется условие или заданное число раз.
  Пример: сумма чисел от 1 до $n$ — начать с $s = 0$, для каждого $i$ от 1 до $n$ прибавлять $i$ к $s$.
