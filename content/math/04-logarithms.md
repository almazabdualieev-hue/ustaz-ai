# Лекция 4. Логарифмы

## 1. Определение логарифма
**Логарифм** числа $b$ по основанию $a$ — это показатель степени, в которую нужно возвести $a$, чтобы получить $b$:
$$\log_a b = c \iff a^c = b$$
Условия: $a > 0$, $a \neq 1$, $b > 0$.
Пример: $\log_2 8 = 3$, потому что $2^3 = 8$.

## 2. Основное логарифмическое тождество и простые свойства
- $a^{\log_a b} = b$
- $\log_a 1 = 0$ (так как $a^0 = 1$)
- $\log_a a = 1$ (так как $a^1 = a$)

## 3. Свойства логарифмов
При $b > 0$, $c > 0$:
- **Логарифм произведения:** $\log_a (bc) = \log_a b + \log_a c$
- **Логарифм частного:** $\log_a \frac{b}{c} = \log_a b - \log_a c$
- **Логарифм степени:** $\log_a b^p = p \log_a b$
- **Переход к новому основанию:** $\log_a b = \frac{\log_c b}{\log_c a}$

## 4. Десятичный и натуральный логарифмы
- **Десятичный:** $\lg b = \log_{10} b$. Пример: $\lg 1000 = 3$.
- **Натуральный:** $\ln b = \log_e b$, где $e \approx 2{,}718$.

## 5. Примеры вычислений
- $\log_3 81 = 4$, так как $3^4 = 81$
- $\log_2 4 + \log_2 8 = \log_2 32 = 5$
- $\log_5 50 - \log_5 2 = \log_5 25 = 2$
- $\log_2 16^3 = 3 \log_2 16 = 3 \cdot 4 = 12$

## 6. Простейшие логарифмические уравнения
Уравнение $\log_a f(x) = c$ решается по определению: $f(x) = a^c$.
Обязательно учитывать **область допустимых значений (ОДЗ)**: выражение под логарифмом должно быть больше нуля.
- $\log_2 x = 5$ → $x = 2^5 = 32$ (ОДЗ: $x > 0$, подходит).
- $\log_3 (x - 1) = 2$ → $x - 1 = 9$ → $x = 10$ (ОДЗ: $x > 1$, подходит).
