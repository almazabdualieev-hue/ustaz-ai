# Лекция 3. Производная

## 1. Определение производной
Пусть аргумент функции $y = f(x)$ получил приращение $\Delta x$, тогда функция получила приращение $\Delta y = f(x + \Delta x) - f(x)$.
**Производная** функции в точке $x$ — предел отношения приращения функции к приращению аргумента, когда приращение аргумента стремится к нулю:
$$f'(x) = \lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x}$$
Нахождение производной называется **дифференцированием**.

## 2. Смысл производной
- **Геометрический:** $f'(x_0)$ равна угловому коэффициенту (тангенсу угла наклона) касательной к графику в точке $x_0$.
- **Физический:** если $s(t)$ — путь, то $s'(t)$ — мгновенная скорость $v(t)$, а $v'(t)$ — ускорение.

## 3. Таблица производных
| Функция | Производная |
|---|---|
| $C$ (константа) | $0$ |
| $x^n$ | $n x^{n-1}$ |
| $\sqrt{x}$ | $\frac{1}{2\sqrt{x}}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $\frac{1}{x}$ |

## 4. Правила дифференцирования
- $(u \pm v)' = u' \pm v'$
- $(C \cdot u)' = C \cdot u'$
- $(u \cdot v)' = u'v + uv'$
- $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$
- **Сложная функция:** $\big(f(g(x))\big)' = f'(g(x)) \cdot g'(x)$

## 5. Примеры
- $(3x^2 - 5x + 2)' = 6x - 5$
- $(x \sin x)' = 1 \cdot \sin x + x \cos x = \sin x + x \cos x$
- $\big((2x + 1)^3\big)' = 3(2x + 1)^2 \cdot 2 = 6(2x + 1)^2$

## 6. Уравнение касательной
Касательная к графику $y = f(x)$ в точке $x_0$:
$$y = f(x_0) + f'(x_0)(x - x_0)$$
Пример: $f(x) = x^2$, $x_0 = 1$. Тогда $f(1) = 1$, $f'(x) = 2x$, $f'(1) = 2$.
$y = 1 + 2(x - 1) = 2x - 1$.
